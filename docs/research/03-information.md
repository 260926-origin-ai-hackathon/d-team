# 避難所における「情報伝達・問い合わせ対応・通信途絶」の課題

調査日: 2026-09-24。取得できた情報だけで構成。取得できなかったものは「未確認」と明記。

## 1. 避難所内の情報伝達手段の実態と問題点

### 1-1 掲示・口頭・放送が主で、届かない人がいる
- 要配慮者が困った情報伝達の課題として「様々な表示が漢字のみの表記のため、子どもや外国の人などが理解できなかった」「掲示物が高いところにあり…視点が低い人などは見えない」「重要な情報伝達を音声のみで行っていたことから、聴覚に障害のある人が食料をもらいそびれた」
  - 出典: 京都府「避難所での課題(要配慮者)」 https://www.pref.kyoto.jp/fukushi-hinan/documents/1.pdf
- 熊本地震の避難者の声「物資が配られるのか、取りに行くのか分からなかった」「マイクがなかったため声が聞こえなかった」。テレビがなくラジオも定時のみで「必要な情報を十分に得られず、被災者はSNSやパソコンを利用」し、その中にデマもあり「何を信じて良いか分からなくなった」。工夫例「掲示物の端に掲示日を記入することで、どれが最新の情報か分かるように」「日中に居ない人などのためにも、必要な情報は個別の手紙」「手書きで作成した避難所に関する新聞を配布」
  - 出典: 内閣府「平成28年度 避難所における被災者支援に関する事例等報告書」 https://www.bousai.go.jp/taisaku/hinanjo/pdf/houkokusyo.pdf (熊本地震 2016)
- 益城町の避難所運営担当者「上からの情報が流れてこない、かつ下からの情報が上に行かない」「電話が鳴りすぎてしまって」。応援職員「行政で決定した事項について、被災者への伝達手段が乏しく感じた。号外のような紙面の配布、宣伝車等、状況に応じて情報伝達手段を考える必要」
  - 出典: 内閣府「平成28年度 熊本地震における避難所運営等の事例(途中経過)」 https://www.bousai.go.jp/updates/h280414jishin/h28kumamoto/pdf/h281025sanko05.pdf
- 珠洲市馬緤町の自主避難所では「『記憶より記録が重要』という方針のもと、センターでの日々の状況、物資の受入、周辺地域の復旧状況などを大判用紙に記録し、壁に掲示して住民へ情報共有」し「口頭伝達による情報の齟齬を避け」た。宝立小中学校(避難者800〜900人)では各教室に「情報連絡係」を置き、毎日9時と16時の定例会議で「情報共有および情報統制(SNSなどで誤った情報が拡散される中、正確な情報を本部から伝えて、避難者の混乱を防ぐ)」を実施
  - 出典: 内閣府「令和6年能登半島地震における避難所運営実態調査報告」(令和8年3月) https://www.bousai.go.jp/taisaku/hinanjo/pdf/r6notojishin_hinanjo_chousa.pdf
- 「行政が、避難所で、情報を張り紙で貼りだし印刷物を置いていても、避難者は疲れていて見に行く心理になれないことがある。そこで、対話して何に困っているかを聞き、ニーズに合致した資料や申込書を手元に届けることで、とやっと情報が使えるようになる」「行政の文章を高齢の被災者が理解するのが難しく、詳しい話を問い合わせるにあたっても、どの窓口が良いのかわからない」
  - 出典: 「令和6年能登半島地震の女性の経験と思いに関するヒアリング調査」(2024年4月25日) https://hokuriku-mf.jp/wp/wp-content/uploads/2024/04/noto_report.pdf

### 1-2 高齢者・スマホ非所持者に届かない
- 「行政からの情報は、LINEに配信されるほか、ウェブサイトに掲載されるが、特に高齢の避難者は、スマートフォンを持っていない場合も多く、情報を得づらい。…紙媒体の広報も発行しているが、二次避難先には十分に届かない(…二次避難所には1部しかなかった)。そこで、この女性が、ミニチュア行政のように、ホームページや支援情報のパンフレットをプリントアウトして回覧している」
  - 出典: 同上ヒアリング調査
- 「今回の災害は、高齢者が多い地域であるため、あまりデジタルに頼らない配慮も求められる」。2次避難先では「週1回紙ベースでの情報提供」。「全省庁の支援制度を網羅的に一つにまとめたガイドブックは被災者にとって有用であり、また紙媒体というのは被災地で活用しやすいという評価」
  - 出典: 中央防災会議「令和6年能登半島地震を踏まえた災害対応の在り方について(報告書)」令和6年11月 https://www.bousai.go.jp/jishin/noto/taisaku_wg_02/pdf/hokoku.pdf
- 富山県民アンケートで「避難所や給水等に関する情報」の入手源は「テレビ」29.0%、「家族や知人、近隣住民」24.4%、「SNS(県・市公式LINE、X等)」22.1%。避難所に無いと困る物資「携帯電話の充電器」26.7%。自由記述「防災行政無線が良く聞き取れない」「給水車などの情報をもっと早く正確に知りたかった(何時〜何時までやあとどのくらい…)」
  - 出典: 富山県「令和6年能登半島地震に係る県民アンケート調査報告書」(令和6年8月) https://www.pref.toyama.jp/documents/42925/kenminankehoukokusyo.pdf
- 防災行政無線について、発災時「内容がわからなかった」が熊本地震調査13.9%に対し能登26.5%。「放送内容は聞こえなかった」「鳴らなかった」人のうち43.6%が困った経験あり
  - 出典: 総務省「令和6年能登半島地震におけるデジタル活用動向等に関する調査」(被災地居住者788サンプル) https://www.soumu.go.jp/johotsusintokei/linkdata/sonota_r06_01.pdf
- LINEの避難所グループで「若い人が、高齢のご家族のスマホを一緒に見ながら、『LINEにこんな情報が来たよ』…とやりとりしていた」。自治体公式アカウントの開封率70〜80%
  - 出典: LINEヤフー https://www.lycorp.co.jp/ja/story/20250731/linegov.html

### 1-3 聴覚障害者
- 「アナウンスが聞こえないために、食料や水の配給を受けられないことがある」「周囲に障害が理解されず、情報から取り残されて孤立しやすい」
  - 出典: 全日本ろうあ連盟 https://www.jfd.or.jp/tohoku-eq2011/shelter-support (東日本大震災 2011)
- 「聴覚障害者は、防災無線や拡声器等による呼びかけでは認識できず、物資や食事の支援情報を得られなかったという事例」。当事者要望「情報を聞き取れない場合に誰に尋ねたら良いのかを分かりやすくしてほしい」。うまく対応できた避難所では「聴覚障害者の携帯電話のメールアドレスを聞き取るなどして、放送文面をメールで送信」。知的障害者は「様々な情報が飛び交う中で、どれが自分に必要な情報なのかを頭の中で整理・判断すること…を考えられず」
  - 出典: 内閣府 H28事例等報告書(上記) (熊本地震 2016)
- 石川県の聴覚障害者支援施設長「耳が聞こえる人なら、館内放送や周囲の人の声を通じて、それほど意識しなくても情報が入ってくるが、聞こえないとみんなの中にいても孤独になりやすい」
  - 出典: 北日本新聞 https://webun.jp/articles/-/545812 (能登半島地震 2024)

## 2. 避難者からの問い合わせの内容と頻度、運営者の負担

- 「一人の被災者に対して一日で4〜5人が同じ質問をすることもあり、被災者もだんだん話さなくなるし、誰を信じればよいのかわからなくなっていた」(保健師等の体調聞き取りが重複)。「庁舎に問い合わせが殺到して職員の対応が不能になり、結果として電話交換機を交換して公衆1回線のみで運用することになった」「地元の職員でなければ回答できないような問い合わせも市民などから多く入り、応援職員では対応できないことが多かった」
  - 出典: 内閣府「熊本地震における避難所運営等の事例」 https://www.bousai.go.jp/updates/h280414jishin/h28kumamoto/pdf/h281025sanko05.pdf
- 石川県検証でも「同情報の複数回聞き取り」が避難者情報の課題として明記。「通信途絶、通信障害により避難所等の状況把握に遅れ」
  - 出典: 石川県「令和6年能登半島地震対策の検証について」 https://www.pref.ishikawa.lg.jp/bousai/bousai_g/bousaikaigi/20241028/documents/03_kensho_gaiyo.pdf
- 「住民からの要望として、いつ頃物資が届くかなど今後の予定を教えてほしいというものがあった。しかし…『プッシュ型』支援の場合、この要望になかなか応えづらかった」。上天草市では「震源地付近の自治体の避難所では食事が配給されたり、風呂が提供されたりしていたのをテレビで確認すると、何で自分たちには食事が配給されないのかといった質問があった」。避難所担当職員の主な業務は「避難者名簿の更新(毎日実施)、情報を掲示板等に掲載、具合の悪い方への配慮」
  - 出典: 小松幸夫(消防防災科学センター)「熊本地震における避難所開設・運営に関する実態」 https://www.isad.or.jp/pdf/information_provision/information_provision/h28/H28_dai3bu3.pdf
- 宝立小中学校では「地域外からも多数の安否確認の問い合わせが寄せられており、対応の効率化が課題」となり、近隣避難所と名簿様式を統一。当初「手書きにより名簿へ氏名を記入してもらっていた。しかし、最大で800〜900人…紙による管理には限界」
  - 出典: 内閣府 避難所運営実態調査報告(令和8年3月)
- 被災自治体職員の自由記述「電話対応で一日が終わり、定時後にやっと事務作業ができる状態」「電話対応、避難所対応、罹災証明の道案内」「休憩時間はあるが、問い合わせや電話、来客対応で休憩中も慌ただしく」。改善要望に「受付事前問い合わせ案内センター」
  - 出典: 自治労石川県本部「能登半島地震による被災自治体におけるメンタルヘルス等に関する実態調査結果」(2024年8月) https://www.jichiro.gr.jp/.assets/%E3%80%90240816%E3%80%91%E8%83%BD%E7%99%BB%E5%8D%8A%E5%B3%B6%E5%9C%B0%E9%9C%87%E3%81%AB%E3%82%88%E3%82%8B%E3%83%A1%E3%83%B3%E3%82%BF%E3%83%AB%E3%83%98%E3%83%AB%E3%82%B9%E3%81%AB%E9%96%A2%E3%81%99%E3%82%8B%E5%AE%9F%E6%85%8B%E8%AA%BF%E6%9F%BB%E7%B5%90.pdf
- NPO側の声「避難所内で各種調査の結果などについて、行政側から情報を流してもらえなかったため、住民から質問されても答えられず、もどかしさを感じた」。「自治体職員がマスコミからの取材対応に時間を割かれることも多く、特に住民からの問い合わせ対応を行うべき電話回線にマスコミからの取材電話も入る」
  - 出典: 内閣府 H28事例等報告書
- 「発災時には不確かな情報がSNSなどで錯綜し、また、自治体にも数多くの問い合わせが殺到する」ため、「AIチャットボットに被災したときに必要となる汎用的なFAQ情報と、基礎自治体単位で持つ流動的(な情報)」を組み合わせる事例
  - 出典: LINEヤフー「防災・減災における『LINE』アプリを活用した事例」2023.10 https://www.lycorp.co.jp/ja/sustainability/jp/common/DisasterResponseEfforts_2310.pdf
- 「SNS等で見た情報に関する問合せは多数寄せられた。特に、LINEオープンチャットで様々な情報が流通」「『○時ごろに××避難所へ物資が届く』という情報が流れると、その避難所に人が殺到」「物資配給に関して、配給日時・場所の嘘の情報が流れていた」
  - 出典: 総務省 デジタル活用動向等調査(上記)
- 輪島市職員「190か所もある自主避難所すべてをどうやってどのように把握するかっていうのはなかった」「避難所という文字が付くだけで避難所班の仕事になってしまう」
  - 出典: 石川県 能登半島地震アーカイブ https://noto-archive.pref.ishikawa.lg.jp/story/wajima6

## 3. 通信途絶の実態

### 3-1 能登半島地震 2024
- 停波基地局は4社合計で最大839局(うち石川県799)、1月3日時点。NTTドコモは能登半島北部の最大7割のエリアが障害。住民証言「山のずっと上のほう、ここから3キロくらいかかる頂上まで行って初めてつながるんです」(1月9日、輪島市77歳男性)
  - 出典: Yahoo!ニュース特集 https://news.yahoo.co.jp/articles/1a38ae9b46e3adaca052c56b409aa15e154f370a
- 応急復旧終了はNTTドコモ1月17日、KDDI・ソフトバンク・楽天モバイル1月15日(立入困難地域除く)。通信各社が最大約100台の車載・可搬型基地局、官民で最大約330台の電源車・発電機。船上基地局で輪島市町野町(1/6〜1/11)、大沢町(1/13〜1/18)を応急復旧。KDDIはStarlink約30台を断絶ケーブルの代替回線に使用
  - 出典: 総務省「令和6年能登半島地震における通信分野の対応」(令和6年7月24日) https://www.soumu.go.jp/main_content/000962902.pdf
- 「通信状況が回復するまでに3週間近くを要した」。停電は最大約4万戸、1月23日時点でも約5千戸未復旧
  - 出典: 日本教育新聞 https://www.kyoiku-press.com/post-273833/
- 珠洲市宝立町(高齢化率56.9%)は「停電:1月8日まで、通信:1月13日まで」、馬緤町(高齢化率62.8%)は「停電:2月1日まで、通信:1月13日まで」。馬緤町では「1月10日頃までは通信が途絶していたため、珠洲市役所とデータを共有する際には、物理的にUSBメモリを持参して渡す方法を検討した。しかし、市役所側のセキュリティにより…LINE等のメッセージアプリを使用して報告した」
  - 出典: 内閣府 避難所運営実態調査報告(令和8年3月)
- 「避難所における通信障害に伴い、避難者の安否確認や支援者同士の連絡調整の困難、県や市町への情報提供の遅延など、様々な活動に支障」。衛星インターネット機器の設置には「アンテナケーブル等の屋内外の配線や電源の確保など…迅速な設置、支障発生時の対応という点で課題」「自治体職員による据付・設定対応への理解の増進が必要」
  - 出典: 中央防災会議WG報告書(上記)
- 電力は「1週間で96%復旧」。被災地居住者で発災時に最初に使ったメディアはテレビ38.5%(全国調査では64.2%)、SNS15.0%、ラジオ2.9%。
  - 出典: 総務省 デジタル活用動向等調査(上記)
- 孤立集落被災者の聞き取り「情報がまったく途絶したために、地震の規模や被害の全体状況、集落内の安否確認、救援の見通しなどがまったくわからず、孤立感をいっそう深めた」
  - 出典: メディア総研 https://note.com/mediareport/n/nd2e75845ac0a

### 3-2 Starlink / 00000JAPAN の実績と限界
- KDDIはStarlink計約700台(避難所向け350台は3日で準備、84か所の避難所に92台を1月11日までに設置)。「発災から通信が使えるようになるまで10日間」。課題「一部の避難所ではStarlinkがうまく設置できていないケース」「集積地によっては食料や日用品などの物資が優先されてなかなか避難所まで運んでもらえない」
  - 出典: KDDI Spark Journal https://spark-journal.kddi.com/tsunagu/article00117/ ; ITmedia https://www.itmedia.co.jp/news/articles/2401/08/news029.html
- ドコモ衛星電話344台、移動基地局90か所、電源車・発電機80か所。KDDI移動基地局84台、ポータブル発電機228台
  - 出典: BUSINESS NETWORK https://businessnetwork.jp/article/18361/
- 00000JAPANは1月1日20〜21時から順次発動、大手は4月22日終了。「通信が暗号化されていない」
  - 出典: WiBiz https://www.wlan-business.org/archives/43065 ; Impress Watch https://www.watch.impress.co.jp/docs/news/1558680.html
- 熊本地震の避難所調査で「携帯電話が使用できない」21.0%。公衆Wi-Fiは「使用できた」23%、「知っていたが使用しなかった」37%、「知らなかった」40%
  - 出典: 総務省 平成29年版情報通信白書 https://www.soumu.go.jp/johotsusintokei/whitepaper/ja/h29/html/nc152230.html

### 3-3 東日本大震災 2011
- 最大約190万回線、基地局約2万9千局が停止。「原因の80%以上が広範囲かつ長期間に及んだ商用電源の停電」。音声は最大70〜95%規制
  - 出典: 総務省 https://www.bousai.go.jp/kaigirep/kentokai/kinoukakuho/2/pdf/1.pdf
- 大槌高校(避難者610名)では「電話、携帯電話も不通となり、外部との情報伝達手段がなくなり」、3月16日に衛星電話貸与(発災5日後)。「コピー機等が使用できないために、書類は手書き」
  - 出典: 東京学芸大 https://u-gakugei.repo.nii.ac.jp/record/30084/files/18804306_63_05.pdf
- 仙台市民7,565人回答。停電中の情報源は「ラジオ」84.3%。震災当日に必要だった情報は「電気・ガス・水道の復旧状況」80.1%、「知人や家族の安否情報」77.8%。避難所に必要な物資「携帯電話の充電器」33.8%
  - 出典: 仙台市 https://www.city.sendai.jp/kekaku/kurashi/anzen/saigaitaisaku/kanren/documents/houkokusyo3.pdf

## 4. 行政情報(罹災証明・支援金・仮設・給水・入浴)が届かない/制度が複雑

- 熊本地震の1年間で行政相談約4,900件、うち罹災証明関係約1,500件。交付率は発災1か月後28.9%、2か月後71.1%、3か月後80.6%。「災害時には建物に関する複数の調査が行われるが、それぞれの調査内容や目的が十分に周知されておらず、被災者が混同した場面」「制度等の周知不足」
  - 出典: 総務省九州管区行政評価局 https://www.soumu.go.jp/main_content/000528758.pdf

## 10. この観点でのまとめ

1. 能登半島地震では基地局停波が最大約840局(1/3)、応急復旧宣言は1/15〜17、現場記録では「通信:1月13日まで」「通信回復まで3週間近く」と、避難所にネットが無い期間が**1〜3週間**存在した。
2. その間、避難所→市役所の報告はUSB持参検討→LINE、物資拠点は「手書きの紙を写真に撮りメール」、熊本では個人携帯→記入用紙持ち回りと、**紙と人力が現実の基幹インフラ**だった。
3. Starlinkは約700台投入されたが、避難所到達まで約10日、設置不良や物資優先で届かない例、電源・配線・設定の負担が課題として公式報告書に残った。00000JAPANは基地局が生きている前提。
4. 避難所内の情報伝達は掲示・館内放送・口頭が中心で、漢字のみ・掲示位置・音声のみのために高齢者・聴覚障害者・外国人に届かない事例が複数災害で繰り返し記録されている。
5. 高齢者はスマホ非所持が多く、LINE/Web配信が届かない。「疲れていて張り紙を見に行く心理になれない」ため、**対話で聞き取り→必要な資料を手渡す**ことで初めて情報が使われた。
6. 避難者からの質問は「配給はいつ・取りに行くのか」「復旧見通し」「給水は何時から」「罹災証明はどこで」「どの窓口か」「薬」「充電」「安否」に集中し、同じ質問が繰り返される(4〜5人が同じ質問/問い合わせ殺到で電話交換機交換)。
7. 制度は「知らなかった34.9%」「わかりにくい17.5〜24.8%」「複数の調査を混同」など、理解の壁が明確で、ガイドブックは28版まで改訂されるほど情報が動く。
8. SNSの真偽不確かな情報を51.9%が目にし、物資配給のデマで人が殺到した。運営本部は「情報統制」に労力を割いた。
9. 外国人向けの多言語表示シート・支援センターは「掲示されない」「存在を知らない」「通信が無いと電話しかできない」で機能せず、翻訳アプリも通信前提。
10. 職員は自らも被災しながら電話・窓口対応で一日が終わり、カスハラも発生。応援職員は「地元の職員でなければ答えられない問い合わせ」に対応できなかった。

## 11. オフラインで動くローカルAIが効く場面／限界

**効く場面(根拠あり)**
- 通信途絶の1〜3週間、掲示板の内容・避難所ルール・本部の決定事項をPCに入れておき、「配給はいつ」「トイレの使い方」「給水は何時から」を何度でも同じ品質で答える(4〜5人が同じ質問、問い合わせ殺到の負担軽減)。
- 掲示物に「掲示日」を入れ最新情報を区別する運用が有効とされた → 更新日時つき知識ベースで「今の最新は何か」を答えられる。
- 「どの窓口か」「罹災証明と応急危険度判定の違い」など制度の交通整理。総務省ガイドブックのような紙資料を事前に投入しておけば、通信なしで参照できる。
- 高齢者・疲弊した避難者に対して「対話して困りごとを聞き、該当資料を手渡す」というヒアリング調査で有効だった方法を、運営者の代わりに一次対応として担う。
- 多言語:「多言語表示を見た人はゼロ」「通訳は1日だけ」「電話しかできない」状況で、翻訳アプリ(要通信)の代替として指さし会話シート的な応答を生成。やさしい日本語への言い換え。
- 聴覚障害者向けに、放送文面をテキスト化して掲示・端末表示(熊本でメール送信が有効だった事例の代替)。
- 運営者向け文書作成:避難者名簿様式、本部への日報(避難者数・物資要請)、掲示物・号外・個別手紙の下書き。手書き名簿が「800人で限界」だった現場でPCが使われた実績あり(宝立小中学校)。
- 電源:主要避難所は1/9までにほぼ通電、電源車約100台が避難所優先で配備されたため、「通信は無いが電気はある」期間が存在する。

**限界(根拠あり)**
- 最新の行政情報(配給予定・罹災証明の受付開始日・2次避難先の空き)は本部からしか来ない。AIは入力された情報しか答えられず、更新が止まると古い情報を自信をもって返すリスク(SNSデマで人が殺到した構図と同じ害になりうる)。
- 「地元の職員でなければ回答できない問い合わせ」=個別事情・判断を要する内容は答えられない。
- 「何で自分たちには配給されないのか」のような不満・苦情、安否確認のような個人情報照会は、AIが一次対応すると火種になる。
- 高齢者はそもそも端末に近づかない/疲れて見に行かない。運営スタッフが端末を持って巡回する運用が必要で、端末を置いただけでは届かない(Wi-Fiを「知らなかった40%」と同じ構図)。
- 電源:停電が2月1日まで続いた地区もあり、ノートPCの電源確保は前提として要検討。Starlink同様「設置・設定は誰がやるか」が現地の課題になった。
- 多言語の精度検証が現場ではできない。
- 「情報が来ない不安」の解消には、AIの回答より「本部からの正確な情報が来る仕組み」(情報連絡係・定例会議)が本質で、AIはその補助に位置づけるべき。
