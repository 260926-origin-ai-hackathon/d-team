## 3. 観点別の知見

### 3-1. TKB(トイレ・キッチン・ベッド)、スフィア基準、「途上国以下」の根拠

- 日本の避難所は1人当たり約2㎡(欧米は4㎡)。雑魚寝は床付近のホコリ・飛沫を吸いやすく、簡易ベッド(床から30cm)で粒子濃度は半分。DVT陽性率30%の避難所もあった。東日本大震災の大規模避難所では1か月で1,000人中30人が寝たきりに。避難所・避難生活学会の榛沢氏は48時間以内にトイレ・温かい食事・ベッドを整える「TKB48」を提唱。
  - 出典: 全日本民医連 https://www.min-iren.gr.jp/news-press/shinbun/20210302_42425.html
- 学会は日本の避難所を「1923年関東大震災以来、大きな進歩は無い」と指摘。仮設トイレは和式が多く、高齢者が利用回数を減らそうと食事・水分を減らし脱水・栄養失調へ。段ボールベッド・パーティションが入るまで「数週間はかかっている」。
  - 出典: メ〜テレ https://www.nagoyatv.com/kurashi-bosai/entry-45021.html
- 能登では段ボールベッド導入決定が発災10日目(1/10)、全体導入は1/16。1/3時点で輪島市の1万人避難者に「2000食しか届いていない」。政府検証は「支援された3,200個のパーティション、7,000個の段ボールベッドが必ずしも活用されなかった」と指摘。
  - 出典: nippon.com https://www.nippon.com/ja/japan-topics/g02476/
- 段ボールベッド搬入に「3週間程度」、「期限切れ間近の菓子パンを泣きながら3日間食べ続けた人」。「寝返りをしたら男性の顔が目の前に」。
  - 出典: Wedge https://wedge.ismedia.jp/articles/-/36521?layout=b
- 自治体の簡易ベッド備蓄は「多くて500台程度」。西日本豪雨では段ボールベッド到着に1週間、胆振東部地震では発災4日目。台湾花蓮地震(2024/4)は数時間で全員分のテント・ベッド配備。
  - 出典: 東京保険医協会 https://www.hokeni.org/docs/2024042200035/
- 内閣府は令和6年12月にガイドラインを改定し、「発災当初から50人に1個、一定期間経過後は20人に1個(女性:男性=3:1)」のトイレ、「1人当たり最低3.5㎡」、「避難所開設時からパーティション・簡易ベッド」、「入浴施設を50人に1つ」を明記。
  - 出典: 内閣府 https://www.bousai.go.jp/taisaku/hinanjo/pdf/2412hinanjo_guideline.pdf
- 能登の避難所で「断水を伴う長期間の避難生活において、食事、風呂、トイレ、洗濯、就寝環境といった生活環境全般に課題」。発災当初は過密で段ボールベッドを置くスペースがなく、被災者が利用を断る例。
  - 出典: 内閣府 検証チーム第3回資料2 https://www.bousai.go.jp/updates/r60101notojishin/pdf/kensho_team3_shiryo02.pdf
- 珠洲市宝立小中学校(想定287人に800〜900人が避難)では上下水道停止を知らずに便器が詰まり、備蓄簡易トイレの使用ルールも共有されず「多くの避難所のトイレにし尿が溜まり不衛生」に。トイレ清掃の負担・役割分担を巡るトラブルも。
  - 出典: 内閣府「令和6年能登半島地震における避難所運営実態調査報告」(令和8年3月) https://www.bousai.go.jp/taisaku/hinanjo/pdf/r6notojishin_hinanjo_chousa.pdf

### 3-2. 災害関連死の数字と原因

- **東日本**: 復興庁が1,263人を分析。「避難所等における生活の肉体・精神的疲労」約3割、「避難所等への移動中の疲労」約2割、「病院の機能停止による初期治療の遅れ等」約2割。66歳以上が約9割、発災1か月以内が約5割。
  - 出典: 復興庁 https://www.reconstruction.go.jp/files/user/topics/20120821_shinsaikanrenshihoukoku.pdf
- **熊本**: 関連死218人の分析(2021/3): 「地震のショック、余震への恐怖による負担」112人(40%)、「避難所等生活の肉体・精神的負担」81人(28.9%)。80代34.4%、70歳以上約8割。
  - 出典: ARROWS https://arrows.peace-winds.org/journal/18354/ 、内閣府 https://www.bousai.go.jp/taisaku/kyuujo/pdf/r01kaigi/siryo8.pdf
- **能登・石川県449人(2025/12/25時点)**: 原因区分(複数選択)「地震のショック・余震恐怖」88.0%、「電気・水道等の途絶による負担」51.9%、「社会福祉施設の被災による介護機能低下」46.5%、「避難所等生活の肉体的・精神的負担」39.2%、「転院・悪路・長時間搬送」18.5%、「コロナ・インフル感染に伴う機能低下」16.0%。年代は80代40.1%、90代37.6%。既往歴あり95.8%。死亡時期は1週間以内9.8%、1か月以内22.9%、2か月以内17.4%、3か月以内13.6%、半年以内23.8%。
  - 出典: 石川県危機対策課 https://www.pref.ishikawa.lg.jp/kisya/r7/documents/1225_kiki.pdf
- **能登・内閣府事例集286件**: 80歳以上82%、既往症あり94%、3か月以内死亡66%。死亡直前の生活環境は病院34%、介護施設等29%、自宅等13.3%、避難所11.2%、親戚知人宅7.7%。経緯キーワード(1か月以内n=72)は「被災のショック等」58、「断水」36、「停電」30、「避難所での生活による心身の負担」17、「避難場所の移動」13、「自宅における避難生活の継続」11、「避難所における感染症罹患」8、「避難所における過密状態」7、「車中泊」5。
  - 出典: 内閣府「災害関連死事例集」(令和8年1月) https://www.bousai.go.jp/taisaku/hisaisyagyousei/pdf/jirei_r8.pdf
- NHKが石川県内201人を分析、「体調が悪化した場所は、最初に身を寄せた避難所が最も多かった」。
  - 出典: NHK https://news.web.nhk/newsweb/na/na-k10014679141000
- 認定例: 珠洲市80代女性「避難所でコロナに感染して持病が悪化し敗血症で死亡」。
  - 出典: PRESIDENT Online https://president.jp/articles/-/83537?page=1
- 死者計748人のうち直接死228人・関連死520人(2026/7/24)。関連死が直接死の2.3倍。
  - 出典: NHK https://news.web.nhk/newsweb/na/nb-3020028355

  - 出典: 内閣府WG「避難生活について」(2024/8) https://www.bousai.go.jp/jishin/noto/taisaku_wg_02/pdf/siryo3_2_1.pdf

### 3-4. 在宅避難・車中泊・自主避難所と「支援から漏れる」問題

- 能登では「指定避難所以外の避難実態は発災から3週間程度ほとんど把握されていなかった」。県が1/19に登録窓口を開設。自己申告の車中泊は93人(1/27)→141人(2/28)。損壊した自宅の納屋・離れ等で生活する人は4,500人。危機対策課の内部調査(2/23〜25)では自主避難所114か所・約1,190人、うち職員配置は8か所193人のみ。
  - 出典: 武田公子(金沢大) https://keikei.w3.kanazawa-u.ac.jp/DP/DP81.pdf
- 「避難所に物資を取りに来ても配布してもらえない事例」があり、内閣府が1/8付で在宅避難者にも配布するよう事務連絡。約300か所の避難所のうち半数近くが自主避難所。
  - 出典: 内閣府 検証チーム第3回、日本教育新聞 https://www.kyoiku-press.com/post-273833/
- 在宅避難者は「名簿等による網羅的な把握が困難」で、「支援ニーズの把握から物資・支援の提供までに時間を要する事例」があり、「災害関連死のリスクを高める要因」。指定避難所が在宅避難者への物資・情報の拠点として機能。
  - 出典: 内閣府 避難所運営実態調査報告
- **熊本**: 「車中泊等の実態把握が困難であり、物資の支援や情報提供が不十分」。グランメッセ熊本は駐車場2,200台が満杯。「昼と夜の避難者数が大きく違い把握困難」。車中泊者は食事・トイレだけ避難所を利用するため食数が読めず。
  - 出典: 熊本県 https://www.bousai.go.jp/kaigirep/kentokai/hinanseikatsu/04/pdf/shiryo7.pdf 、内閣府H28事例報告書
- 車中泊は燃料不足、積雪でマフラーが塞がれ一酸化炭素中毒の危険。「自宅に帰れず、避難所にも入れず、2次避難もできない人たち」。
  - 出典: SOTOBIRA https://sotobira.com/_ct/17685098
- 在宅避難者は「救助法の対象外とされ、国の支援が受けられない」状況だったが、2025年改正で福祉的支援費用を国が負担。
  - 出典: ケアニュース https://www.care-news.jp/news/Iy5TJ

### 3-5. 高齢化した被災地と福祉避難所の機能不全

- 高齢化率は珠洲市51.6%、能登町50.4%、穴水町49.1%、輪島市46.0%、志賀町44.6%、七尾市38.5%(2020国勢調査)。能登6市町計約44%(全国約29%)。
  - 出典: 石川県デジタル推進監室 https://www.soumu.go.jp/main_content/000998548.pdf 、SOMPO https://www.sompo-ri.co.jp/2025/03/07/16901/
- 平時に指定・協定していた福祉避難所71か所のうち、1/8時点で開設できたのは10か所。最大でも30か所(4/1時点)。「施設の被害や職員等の被災等により、開設は一部に留まった」。
  - 出典: 内閣府 検証チーム第3回
- 障害者は「被災した自宅で支援を待っている状態が多く、支援物資が各家庭に配布されない状況下で孤立」。「避難所のトイレは障害者が使用するのが難しく、障害者が避難所に行かない一つの要因」。
  - 出典: 中央防災会議報告書、武田DP81
- 関連死の46.5%に「社会福祉施設の被災による介護機能の低下」が関与(石川県)。

### 3-6. 国の最新方針(2024〜2025)

- 内閣府「避難生活における良好な生活環境の確保に向けた取組指針」「避難所運営等避難生活支援のためのガイドライン(チェックリスト)」「トイレ確保・管理ガイドライン」を令和6年12月13日改定。トイレカー・トイレトレーラー、キッチンカー・調理人派遣、開設時からのパーティション・段ボールベッド、仮設風呂資機材の備蓄を追記。 https://www.bousai.go.jp/taisaku/hinanjo/index.html
- 中央防災会議報告(2024/11): 「場所(避難所)の支援」から「人(避難者)の支援」へ転換、在宅・車中泊避難者を含む支援、トイレカー等の登録制度、段ボールベッド規格化。 https://www.bousai.go.jp/jishin/noto/taisaku_wg_02/pdf/hokoku.pdf
- 改正災害対策基本法・改正災害救助法(2025/5/28成立): 次官級「防災監」設置、備蓄状況の公表義務化、「被災者援護協力団体」登録制度、物資供給・被災者情報把握のデジタルツール活用努力義務、災害救助法に「福祉サービスの提供」を72年ぶりに追加。 https://news.yahoo.co.jp/expert/articles/cbcd3bed547d54fd47c43dc003d881a8c3de94c2
- 「避難生活支援・防災人材育成エコシステム」: 避難生活支援リーダー/サポーター研修は令和4年度以降、延べ21市町村965名受講。目標は「災害関連死・ゼロ」。 https://www.bousai.go.jp/kyoiku/bousai-vol/hinanseikatsusien.html
- 内閣府「避難所運営実態調査報告」(令和8年3月): 避難所運営を「受付・名簿管理、物資管理、食事調整、衛生・清掃、入浴支援、防犯、健康管理、要配慮者対応」に分解し、住民主体＋NPO＋応援職員の3パターン運営モデルと「コーディネーター機能」の必要性を提示。

## 4. この観点でのまとめ

1. 避難者アンケートで一貫して上位に来るのは「トイレ」(59〜62%)、「眠れる環境・寝床」(66%)、「食事」(50%)、「プライバシー」で、能登(厳冬期)では「寒さ」34.4%が最上位に来た。
2. トイレは「数の不足」(81.5%)だけでなく「衛生」(39%)「使用ルールが不明確」(20.7%)が問題で、水分を控えて脱水・DVT・関連死につながる連鎖が公式資料でも繰り返し指摘されている。
3. 関連死は直接死を上回る(熊本4.5倍、能登2.3倍)。能登の関連死449人の39.2%に「避難所等生活の負担」、51.9%に「電気・水道途絶」、46.5%に「介護機能低下」が関与し、80歳以上が約8割、既往歴ありが96%。
4. 死亡時期は発災1か月以内が3割強、3か月以内で6割超。「最初に身を寄せた避難所」で体調悪化が最多(NHK分析)であり、初動〜1か月の避難所環境が命に直結する。
5. 能登では避難所の半数近くが自主避難所、在宅・車中泊の実態は3週間把握されず、「物資を取りに来ても配布されない」事例があった。熊本でも車中泊74.5%で把握不能。「避難所外の被災者にどう情報と物資を届けるか」が最大の穴。
6. 高齢化率50%前後の地域では福祉避難所71か所中10か所しか開けず、避難所運営を担う住民・職員自身が被災者かつ高齢。運営リーダーへの依存と疲弊が構造問題。
7. 運営現場の負担は「名簿・安否確認」「物資の在庫と公平配布」「食数調整」「炊き出し申し出の重複調整」「トイレ清掃の役割分担」「ルール周知」「正確な情報の統制(SNS誤情報対策)」に集中しており、多くが紙・手書き・口頭で処理されていた。
8. 情報面では、テレビ・家族知人・SNSに分散し、高齢者は対面情報に依存。通信障害は3週間続き、臨時災害放送局は「職員が多忙で」開局されなかった。オフラインで動く情報拠点の空白がある。
9. 国は令和6年12月ガイドライン改定(50人→20人に1基、3.5㎡、開設時からベッド・パーティション)、2025年改正法(場所から人へ、防災DX努力義務、福祉サービス追加)、人材エコシステムで「災害関連死ゼロ」を掲げたが、実装は自治体・住民の手にある。
10. 未確認事項: 西日本豪雨の避難所閉鎖日と関連死総数、奥能登豪雨の関連死単独数、Civic Force調査の各%、能登での消灯・飲酒トラブルの個別報道。企画上はこれらを「未記録」として扱うのが安全。
