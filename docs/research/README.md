## 1. 10行で言うと

1. **人は桁違いに足りない。** 益城町は職員約250名に対し避難者最大16,000人。熊本市は「職員のほとんどが避難所担当、2人1組で交代なし」。輪島市は「各避難所2名が24時間常駐」、1人で5避難所を担当した職員もいた。
2. **職員自身が被災者で、休めない。** 益城町職員の85.2%が自宅被害。能登の被災自治体職員は時間外月100〜240時間、「電話対応で一日が終わり、定時後にやっと事務作業」。避難所運営職員の82%が症状を抱えながら勤務。
3. **時間を奪うのは定型作業。** 名簿の手書きと様式変更による二度手間、3時間ごとの状況報告、日報、物資の在庫把握、安否照会、同じ質問への繰り返し回答、交代のたびの引継ぎ。
4. **「言い出せない」は構造の問題。** 「同じ地区の顔見知りだから」「運営も物資担当も男性だから」「言うと居づらくなる」。能登でも「陰部がかゆい、膀胱炎、をみんなで話せずに我慢」が再現。育児中女性の45.6%が「迷惑をかける」と在宅にとどまり、アレルギー患者の95.8%は避難所に行かない。
5. **言えない人は避難所から消える。** 「周りに迷惑」が理由の退所は要援護者で一般の2.5倍。熊本では避難者の74.5%が車中泊し把握不能に。避難所外への巡回は「なかった」が85%。
6. **通信は1〜3週間途絶する。** 能登では基地局停波最大839局、現場記録で「通信:1月13日まで」、復旧まで「3週間近く」。その間は紙・手書き・USB持参・口頭が基幹インフラだった。Starlinkは約700台投入されたが避難所到達まで約10日。
7. **情報は掲示・放送・口頭で、届かない人がいる。** 漢字のみの掲示、音声のみの伝達、高すぎる掲示位置。高齢者はスマホ非所持でLINE配信が届かず、「疲れていて張り紙を見に行く心理になれない」。外国人約1,600人がいた奥能登で「避難所で多言語表示を見た人はゼロ」。
8. **既存の避難所DXは全部クラウド前提。** 防災DXサービスマップ101件の避難所支援サービスは受付・名簿・混雑が中心で、通信がないと動かない。生成AI活用も制度案内ボット（OpenAI API）と災対本部支援に限られ、避難所端末で完結するものは国内に見当たらない（未確認）。
9. **関連死は直接死を上回り、初動〜1か月の避難所環境で決まる。** 熊本4.5倍、能登2.3倍。能登の関連死449人の39.2%に「避難所等生活の負担」が関与、80歳以上が約8割。「最初に身を寄せた避難所」で体調悪化が最多。
10. **国の方針はローカルLLMと整合する。** 2024年12月ガイドライン改定は「困りごと相談窓口」「女性・要配慮者の意見」「引継ぎ体制」を要求。文科省BRIDGEは防災AIに「RAGで根拠を縛る」「個人情報を外に出さない」を要件化。改正法（2025年5月）はデジタルツール活用を努力義務化した。

## 3. テーマ別の要点

### 3-1 人手不足・運営者の負担（→ [01-staffing.md](01-staffing.md)）
- 中央防災会議が熊本地震で「避難所運営に多数の市町村職員が忙殺され、復旧や復興への行政事務の実施が困難」と公式に認定。能登でも同じ構図が再現し、穴水町は応援職員が運営を担って初めて「通常業務に専念」できた。
- 対口支援は不可欠だが、ローテーションで「引継ぎに限界」「職員によって対応方針が異なる」「地域のことが分からない」「毎日人が変わり避難者の評判が悪い」（熊本・能登で共通）。
- 住民の自主運営は地縁の強い地域では機能するが、都市部・大規模避難所ではリーダーが現れず、特定リーダーの疲弊・退所で崩れる。自主運営が機能した宝立小中でも名簿・物資は応援職員が担った。
- 学校が避難所になると教職員が中核を担わされる。宮城では避難所設置校の約半分が教職員のみで運営、大槌高校は不眠不休で名簿・掲示・安否対応・物資配給・報告まで担当。
- ガイドライン（2024年12月改定）は「引継ぎ体制」「運営職員のストレス相談担当」「職員以外でも立ち上げられる手引」を求めるが、避難者N人あたり職員M人という基準はない。

### 3-2 言い出せない・聞きにくい（→ [02-unspoken-needs.md](02-unspoken-needs.md)）
- 内閣府の公式調査（能登2025・東日本2012）が「改善を訴えると人間関係に影響」「要望を言うと肩身が狭い・出ていかなければならない不安」を記録。個人の性格ではなく構造。
- 女性の身体に関すること（生理用品の追加、下着、着替え、陰部のかゆみ、膀胱炎）は「みんなで話せずに我慢」が13年間改善していない。物資担当が男性で「言わないと男性は立ち退かない」。男性も「尿もれパッドが欲しかったが言い出せなかった」。
- 障害者・乳幼児連れ・持病・アレルギー・LGBTQ・外国人は「迷惑をかける」「そのくらい我慢できるでしょと言われる」「不審者扱いされる」「そもそも避難所に入っていいと思っていない」で、自ら避難所を離れるか来ない。
- 性暴力・DVは相談しても「我慢しろ」「若いから仕方ない」と二次被害。顔見知り加害だと被害届を出さない。相談後の安全確保がなければ声を上げること自体が危険。
- 意見箱・相談窓口・巡回は制度上推奨されているが、設置率は21〜43%、相談員常駐33.3%。理由は「人員がいない」「精一杯」。成功例（トイレの「みんなの声」箱）は匿名・人目のない場所・書く形式だった。スフィア基準は「匿名性を保障する手段」と「機密保持」を要求。

### 3-3 情報伝達・問い合わせ・通信途絶（→ [03-information.md](03-information.md)）
- よくある質問は「配給はいつ・取りに行くのか」「復旧の見通し」「給水は何時から」「罹災証明はどこで・どの窓口か」「薬」「充電」「安否」「トイレの使い方」に集中し、同じ質問が繰り返される（「1日で4〜5人が同じ質問」「問い合わせ殺到で電話交換機を交換」）。33件の具体例を出典付きで一覧化した。
- 能登では避難所→市役所の報告にUSB持参を検討しLINEで送った。熊本では個人携帯→記入用紙持ち回り→タブレットと変遷。物資拠点は「手書きの紙を写真に撮りメール」。
- 「疲れていて張り紙を見に行く心理になれない」ため、対話で困りごとを聞いて該当資料を手渡すことで初めて情報が使われた（能登 女性ヒアリング）。
- 制度は「知らなかった34.9%」「わかりにくい」「複数の建物調査を混同」。総務省の被災者ガイドブックは28版まで改訂されるほど情報が動く。
- 多言語表示シート・多言語支援センターは「掲示されない」「存在を知らない」「通信がないと電話しかできない」で機能せず、翻訳アプリも通信前提。「やさしい日本語」の需要が英語を上回る（検索要約のみ）。

### 3-4 防災DX・AIの先行事例（→ [04-dx-landscape.md](04-dx-landscape.md)）
- 先行事例16件を一覧化。デジタル庁避難所PoC、Suica避難者把握、くまもとアプリ、SOCDA、LINE FAQボット、東武トップツアーズ被災者支援AI、NTT東×横須賀市 災対本部AI、文科省BRIDGE など。すべて通信またはクラウド前提。オフライン明記は能美防災N-HOPSのみ。
- 能登でSuica配布が始まったのは発災5週間後。マイナカードはリーダー未整備で使えず。「減った1.5万人のうち所在が確認できるのは2千名」。
- 職員の本音（デジタル庁R6実証）: 「電源、電波がないと使い物にならない」「有事にしか使わないシステムは使いこなせない」「全避難所にPCは置けない」「結局は手書き対応になりそう」。
- 海外研究（Pocket RAG、TRIDENT）はオンデバイスSLM＋RAGで応急手当・トリアージを扱い、「避難所への事前配置」を明示的に提案。国内のローカルLLM×避難所実証は見当たらない（未確認）。
- 電源は指定避難所の61.1%、学校避難所の77.2%に非常用発電機等がある。ノートPC1台なら過半の避難所で動く。

### 3-5 生活環境・関連死・統計（→ [05-living-conditions.md](05-living-conditions.md)）
- 困りごとの上位は一貫してトイレ、寝床、食事、プライバシー。能登（厳冬期）は「寒かった」34.4%が最上位。
- トイレは「数」だけでなく「衛生」「使用ルールが不明確」が問題で、水分を控えて脱水・DVT・関連死に至る連鎖が公式資料で繰り返し指摘されている。
- 段ボールベッド搬入は能登で3週間、備蓄は「多くて500台」。日本の避難所は「関東大震災以来大きな進歩は無い」（避難所・避難生活学会）。
- 能登では避難所の半数近くが自主避難所で、在宅・車中泊の実態は3週間把握されず「物資を取りに来ても配布されない」事例が出た。福祉避難所は71か所中10か所しか開けなかった。
- 国は2024年12月ガイドライン改定（トイレ20人に1基、3.5㎡、開設時からベッド）、2025年改正法（「場所」から「人」への支援、デジタル活用努力義務）で「災害関連死ゼロ」を掲げた。

## 4. ローカルAI企画への示唆

### 4-1 この調査から導ける機能マップ

| 現場の困りごと（根拠） | ローカルAIの役割 | 利用者 |
|---|---|---|
| 同じ質問への繰り返し対応、電話・窓口で一日が終わる（自治労石川、内閣府熊本事例） | 避難所ルール・配給予定・給水時間・制度案内・窓口案内のFAQ応答。通信不要で24時間 | 避難者・運営者 |
| 交代のたびに引継ぎに限界、対応方針がぶれる（能登町、熊本市） | 決定事項・対応ログを蓄積し、次の担当者に「昨日までの経緯」を要約提示 | 応援職員・運営者 |
| 3時間ごとの状況報告、日報、物資発注報告（デジタル庁、能登町スケジュール） | 名簿・在庫・トイレ状況の入力から報告書・日報を生成。統一様式への転記の二度手間を解消 | 運営者 |
| 手書き名簿が800人で限界、安否照会が多数（宝立小中） | 名簿の構造化入力補助、安否照会の一次回答（個人情報の扱いは要設計） | 運営者 |
| 掲示物・号外・個別手紙・放送原稿の作成負担（大槌高校、内閣府熊本事例） | 決定事項から掲示文・館内放送原稿・やさしい日本語版・多言語版を生成。掲示日を自動付記 | 運営者 |
| 「聞くのが恥ずかしい」「顔見知りに知られたくない」（能登女性ヒアリング、女性支援ネットワーク） | 匿名で質問できる窓口。身体系の質問、相談先の案内、性被害・DVの「匿名の入口」 | 避難者 |
| 「そのくらい我慢しろ」と言われそうな人の申し出ハードル（内閣府H28、総務省アレルギー調査） | アレルギー対応食・服薬・障害配慮の有無を人に聞かず確認できる | 要配慮者 |
| 多言語表示を誰も見ていない、通訳は1日だけ（CLAIR、内閣府熊本事例） | 自分の言語で聞ける。指さし会話シート的な応答生成 | 外国人避難者 |
| 音声のみの伝達で聴覚障害者が配給をもらいそびれる（内閣府熊本事例） | 放送文面のテキスト化・端末表示 | 聴覚障害者 |
| 応援職員が「地域のことも、何をすべきかも分からない」（熊本市、能登WG） | 当該避難所のローカル知識（地区・施設・ルール・要配慮者対応）のオンボーディング | 応援職員 |
| 相談窓口を置く人員がない（内閣府H28） | 匿名相談のログを匿名集計し、運営会議に「今日の困りごと傾向」として渡す | 運営委員会 |

### 4-2 設計上の制約（一次資料から）

- **静的知識と動的情報を分ける。** マニュアル・制度・ルールは事前投入できるが、配給予定・罹災証明の受付開始・2次避難先の空きは本部からしか来ない。更新が止まった情報を自信をもって返すと、SNSデマで人が殺到した構図と同じ害になる。回答には必ず「いつ時点の情報か」を付ける。
- **RAG＋出典表示＋「窓口へ確認」の常時表示が最低要件。** ベンダー自身が「100%ではない」と明記し、文科省BRIDGEも誤情報検出を必須要件にしている。
- **個人情報は端末外に出さない。** これはBRIDGEの要件でもあり、オフライン設計の最大の正当化根拠。ただし名簿・安否照会を扱うなら、画面の覗き見防止・履歴消去・匿名化の設計を示せないと使われない。
- **高齢者は端末に近づかない。** 関連死の約8割は70代以上。「Wi-Fiを知らなかった40%」と同じ構図で、置いただけでは届かない。運営者が端末を持って巡回する、大画面・音声UIにする、設置場所（トイレ付近・女性専用スペース・個室）を選ぶ。
- **匿名で聞けても、改善要求は運営者に届く必要がある。** 「言えない」の本質は「言った後の人間関係」。匿名集計→運営会議へ、というループがないと「聞いただけ」で終わる。子どもの「話しても何も変わらない」16.6%を再現しない。
- **性暴力・DVはAI単体では危険になりうる。** 相談後の行き先（分離・安全確保）が見えないなかで声を上げさせるのは被害者をさらに危険にする。AIは相談カード・警察・女性相談への「入口」に徹する。
- **「年1回しか使わない」問題はローカルLLMでも同じ。** 平時利用（訓練、マニュアル検索、研修、TTX）を組み込まないと「担当者がシステムに不慣れ」を再現する。
- **電源は過半の避難所にあるが、照明・暖房・充電と競合する。** 停電が2月1日まで続いた地区もある。低消費電力モデル、バッテリー運用時間の実測が必要。
- **差別化は「Starlinkが来るまでの72時間〜3週間」と「Starlinkが来ない小規模・自主避難所」に絞る。** 国のBRIDGEやStarlink常備が進むと「オフライン」の優位は縮む。

### 4-3 効かない場面（正直に）

- 「自分が何に困っているのか分からない」「声かけに『大丈夫』と答える」層は質問すること自体をしない。プッシュ型の巡回・声かけの代替にはならない。
- 車中泊・在宅避難者は避難所のPCの前に来ない。最も把握できていない層には、避難所が物資・情報の拠点として機能する場面でしか接点がない。
- 「何で自分たちには配給されないのか」のような不満・苦情や、個別判断を要する問い合わせ（全壊判定の妥当性）は、AIが一次対応すると火種になる。
- 「情報が来ない不安」の本質は本部からの正確な情報が来る仕組み（情報連絡係・定例会議）であり、AIはその補助。
