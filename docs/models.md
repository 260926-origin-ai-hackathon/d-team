# モデルの選び方

Ollama で `ollama pull <名前>` するだけで切り替えられます。
ノートPC向けの現実的な候補（2026-09 時点）:

| モデル | ダウンロード | 目安 RAM | 文脈長 | 画像 | 日本語 | 用途 |
|---|---|---|---|---|---|---|
| `gemma3:270m` | 0.3GB | 2GB | 32K | × | △ | 分類・タグ付けなど超軽量 |
| `gemma3:1b` | 0.8GB | 4GB | 32K | × | ○ | 低スペックPC・要約 |
| `qwen3.5:2b` | 2.7GB | 8GB | 256K | ○ | ○ | 軽量汎用 |
| `qwen3.5:4b` | 3.4GB | 8GB | 256K | ○ | ◎ | **既定**。汎用・JSON・ツール |
| `gemma3:4b` | 3.3GB | 8GB | 128K | ○ | ◎ | qwen3.5:4b の代替 |
| `qwen3.5:9b` | 6.6GB | 16GB | 256K | ○ | ◎ | 品質重視（GPU 推奨） |

目安 RAM は「モデルサイズ + 4GB 程度」。それより余裕があれば動きます。

## 速度の目安

- CPU のみ（4コア Core i5 相当）: 4b で 5〜10 トークン/秒。日本語は 1 トークン ≒ 1〜2 文字
- NVIDIA GPU（VRAM 6GB 以上）: 4b で 40〜100 トークン/秒
- 初回はモデルをメモリに読み込むので 30〜60 秒かかる。2回目以降は数秒

## 設定で速くする

`.env`（無ければ `.env.example` をコピー）:

```
LOCALAI_NUM_CTX=4096      # 文脈長を短くするとメモリ・速度が改善（既定 8192）
LOCALAI_TEMPERATURE=0.2   # 抽出・要約は低め、アイデア出しは高め
```

## thinking（推論）モードについて

`qwen3.5` は thinking 機能を持ちますが、このキットでは応答速度を優先して **無効（think=False）** にしています。
複雑な推論をさせたい場合は `localai/client.py` の `think=False` を `True` に変えてください（応答は遅くなります）。

## 別のモデルを使うには

```powershell
ollama pull gemma3:4b
```

その後 `.env` の `LOCALAI_MODEL=gemma3:4b` に変更。UI ではサイドバーのプルダウンで選べます。
モデルの一覧は https://ollama.com/library
